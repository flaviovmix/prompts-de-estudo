# JSON na Prática · aula 1.02 · Os valores e o objeto

- [tarefa.json](tarefa.json): a tarefa da aula, inteira, com os quatro pares e os quatro tipos de valor: titulo (texto), feita (verdadeiro ou falso), prioridade (número) e prazo (nulo).

Pra baixar: clique no arquivo e, na página dele, no botão de baixar (Download raw file, a setinha pra baixo, em cima, à direita). Ele vai pra pasta Downloads.

Pra abrir: arraste o arquivo pra dentro da janela do VS Code.

Depois, mexa nele, como a aula pede: troque o false por true, mude a prioridade, apague uma aspa e veja o vermelho aparecer.
