- No Windows, o Tomcat procura o Java pela variável JAVA_HOME, que a instalação da Temurin não cria. Eu criei pela janela Variáveis de Ambiente ("Editar as variáveis de ambiente para sua conta", Novo, nome JAVA_HOME, Procurar no Diretório até a pasta jdk-25..., não a bin).
