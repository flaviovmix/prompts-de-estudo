# Java para a Web, aula 1.03: Preparar a interface do LabApp · material

A interface do LabApp vem pronta num arquivo zip: [labapp.zip](labapp.zip) (uns 6 KB).
Clique nele e, na página do arquivo, no botão de baixar (Download raw file, a setinha pra baixo, em cima, à direita). Ele vai pra pasta Downloads.

Dentro vem uma pasta labapp com oito arquivos: o index.html, seis arquivos de estilo (.css) e o abre-janela.js.

Pra descompactar dentro do Tomcat, no terminal que começa na sua pasta de usuário:

```text
tar -xf Downloads\labapp.zip -C apache-tomcat-11.0.27\webapps
```
