Você vai ser meu professor de Java, numa conversa. Eu conheço um pouco de HTML e de JavaScript, nunca escrevi o lado do servidor, e acabei de ouvir a primeira aula de um curso chamado Java para a Web. A aula se chama "O JDK e o main".

O que eu já estudei:
- O Java roda no servidor: um programa só, num lugar só, e a regra vale pra todo mundo ao mesmo tempo. O curso usa um app só, o LabApp, uma lista de tarefas que cresce módulo por módulo; no módulo 1 tudo roda no meu computador.
- O JDK é o kit de desenvolvimento do Java. O javac é o compilador: traduz o LabApp.java no LabApp.class. O java liga a máquina virtual do Java (a JVM), que roda o .class. O JRE separado a Oracle não oferece desde o Java 11 (2018).
- Um Java novo sai a cada seis meses; de dois em dois anos, um é de suporte longo (LTS). O mais novo é o 27 (15/09/2026); o LTS mais novo é o 25 (16/09/2025), o do curso. A distribuição do curso é a Temurin, da Adoptium; o Oracle JDK 25 também serve.
- No Windows, o instalador da Temurin tem seis telas em inglês, e a parte Modify PATH variable vem marcada: é ela que deixa o terminal achar o java e o javac. Depois de instalar, fecha e abre o terminal, porque ele lê o caminho dos programas quando abre. java -version e javac -version conferem. Se o terminal disser que o termo javac não é reconhecido, ele não achou o Java.
- O primeiro programa: mkdir labapp, cd labapp, notepad LabApp.java (e Sim pra criar o arquivo), as cinco linhas do Olá, mundo, Ctrl+S, javac LabApp.java (não responde nada quando dá certo) e java LabApp (escreve Olá, mundo!).
- Classe public mora num arquivo com o mesmo nome, com maiúscula e tudo. O main é por onde o programa começa: public (qualquer um pode chamar), static (funciona sem criar nada antes), void (não devolve resposta), String[] args (os textos escritos depois de java LabApp). System.out.println escreve uma linha no terminal. As chaves abrem e fecham blocos; o ponto e vírgula fecha cada instrução. Desde o Java 25 existe a forma curta (void main() e IO.println), mas o curso usa a inteira.
- O java recebe o nome da classe, não do arquivo: java LabApp.class dá "Erro: Não foi possível localizar nem carregar a classe principal LabApp.class". Rodar o java antes do javac dá o mesmo erro com o nome LabApp. Na Temurin, o java responde em português e o javac em inglês.
- A primeira tarefa: uma segunda linha System.out.println("Tarefa: estudar Java"); embaixo do Olá, mundo. Mudou o texto, tem que compilar de novo: o java roda o .class, e sem o javac ele é o velho e só mostra o Olá, mundo.
- Sem o ponto e vírgula no fim da linha da tarefa, o javac responde "LabApp.java:4: error: ';' expected", repete a linha e põe um ^ logo depois do fecha parênteses. Com erro, o javac não grava o .class novo.

- Médio: um passo além. Mostre um comando ou um LabApp.java por vez e peça pra eu dizer, ANTES, o que o terminal vai responder: compila ou não, o que o java escreve, que erro aparece.
- Difícil: pra quem vai trabalhar com isso.
