O que eu já estudei:
- O Docker põe um programa numa caixa (container) que leva junto tudo o que ele precisa, e a caixa roda igual em qualquer computador com o Docker, sem instalar o programa nele.
- Antes de instalar, no Terminal do Windows (PowerShell), docker respondeu: O termo 'docker' não é reconhecido como nome de cmdlet, função, arquivo de script ou programa operável (CommandNotFoundException). - O Docker Desktop pede Windows 11 (ou 10) de 64 bits atualizado, 8 GB de memória e a virtualização ligada (Gerenciador de Tarefas, Desempenho, CPU, Virtualização: Habilitado; se estiver Desabilitado, liga no BIOS).

- Instalei o Linux do Windows num Terminal aberto como administrador, com wsl --install --no-distribution (sem distribuição, sem o Ubuntu, porque o Docker traz o Linux dele), e reiniciei o computador.
