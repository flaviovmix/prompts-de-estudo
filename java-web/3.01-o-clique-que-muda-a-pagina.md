Você vai ser meu professor de JavaScript. Estou começando a programar: fiz uma aula de HTML, uma de CSS e acabei de fazer a minha primeira aula de JavaScript.

O que eu já estudei:
- O HTML diz o que cada coisa é, o CSS diz como ela aparece e o JavaScript diz o que a página faz quando alguém mexe nela. JavaScript não é Java.
- O Console do navegador (F12) roda o que eu digito e responde embaixo. É nele que aparecem os avisos e os erros do código da página.
- O JavaScript pode ser escrito em três lugares: dentro da marca (o atributo onclick), no próprio arquivo (a marca script) e num arquivo separado (o lista.js, apontado pelo src da marca script).
- alert abre uma janela de aviso; console.log escreve no Console, e não na página.
- Variável é um nome que guarda um valor. const é pro valor que não vai ser trocado, e let pro que pode ser trocado. typeof diz o tipo: string (texto), number (número) e boolean (true ou false).
- Função: a palavra function, o nome, os parâmetros entre parênteses e, entre chaves, o que ela faz. return devolve a resposta. A função só roda quando é chamada pelo nome, com parênteses.
- document.querySelector acha um elemento da página pelo mesmo seletor do CSS, e devolve null quando não acha.
- botao.addEventListener("click", funcao) faz a função rodar a cada clique. O nome da função vai sem parênteses.
- document.createElement cria um elemento, textContent põe texto nele (e o texto não vira marca), appendChild pendura no fim de outro elemento, e o value de um campo é o que está digitado nele.
- A página é lida de cima pra baixo: a marca script no head roda antes de a lista existir, as buscas devolvem null, e o erro aparece no Console.
- O que o JavaScript põe na página não vai pro arquivo: ao atualizar, a página volta a ser a do arquivo.

O código da aula, pros níveis médio e difícil:
<label for="novo">Novo chamado</label>
<input id="novo" type="text">
<button id="adicionar" type="button">Adicionar chamado</button>
<ul id="lista">
  <li class="aberto">Impressora do financeiro não imprime</li>
</ul>
<script src="lista.js"></script>

const lista = document.querySelector("#lista");
const campo = document.querySelector("#novo");
const botao = document.querySelector("#adicionar");

function adicionarChamado() {
  const item = document.createElement("li");
  item.textContent = campo.value;
  lista.appendChild(item);
  campo.value = "";
}

botao.addEventListener("click", adicionarChamado);
