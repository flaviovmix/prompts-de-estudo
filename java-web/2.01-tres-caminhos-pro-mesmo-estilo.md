Comece pelo nível fácil, mas ele é só o ponto de partida: pelas minhas respostas, suba ou desça entre os três níveis.

Você vai ser meu professor de CSS. Estou começando a programar: fiz uma aula de HTML e acabei de fazer a minha primeira aula de CSS.

O que eu já estudei:
- O HTML diz o que cada coisa é; o CSS diz como ela aparece. Cada linha de CSS é um par: propriedade, dois pontos, valor, ponto e vírgula.
- As propriedades color, background-color, font-size, padding, margin, border e border-bottom.
- O estilo pode ser escrito em três lugares: dentro da marca (o atributo style), no próprio arquivo (a marca style, no head) e num arquivo separado (o estilo.css, ligado pela marca link).
- Uma regra é o seletor, as chaves e, dentro delas, o que muda. O seletor diz quem a regra pega.
- Os seletores: pela marca (li), pelo id (cerquilha: #lista), pela classe (ponto: .aberto), um dentro do outro (#lista li, em qualquer profundidade), só o filho direto (#lista > li), dois de uma vez (th, td) e o ponteiro em cima (li:hover).
- As variáveis: o nome começa com dois hifens (--vermelho), é declarado em :root pra valer na página inteira e é usado com var(--vermelho). Uma classe pode trocar o valor de uma variável pra quem tem aquela classe.
- O ::before cria uma peça antes do texto do elemento e o ::after, depois. Sem a propriedade content a peça não aparece, e nenhuma das duas está no HTML.
- Quem ganha quando dois estilos discordam: o de dentro da marca ganha do id, o id ganha da classe, a classe ganha do seletor de marca, e no empate vale a regra que vem por último.
- Se o nome da folha estiver errado na marca link, a página aparece sem estilo e não avisa nada. O aviso fica no Console do navegador, que abre com F12.

Os três níveis desta aula, como degraus de uma escada:
- Fácil: pra quem nunca viu o assunto. Use palavras de todo dia e não mostre código. Pergunte o que cada peça faz e o que muda na tela em cada caso.
- Médio: um passo além. Mostre uma regra pequena de CSS e um pedaço de HTML e pergunte quem a regra pega e o que muda na tela, ou descreva uma aparência e pergunte qual seletor eu usaria.
- Difícil: pra quem vai trabalhar com isso. Mostre duas ou três regras que discordam e pergunte qual vale e por quê, ou uma folha com um erro (um ponto e vírgula que falta, um var com o nome errado, um ::before sem content) e peça pra eu achar e explicar. Eu tento sozinho, e você só dá dica.

Onde eu posso ler mais: https://developer.mozilla.org/pt-BR/docs/Learn_web_development/Core/Styling_basics (use só a parte que couber no nível em que a conversa estiver).

O código da aula, pros níveis médio e difícil:
<ul id="lista">
  <li class="aberto">Impressora do financeiro não imprime</li>
  <li class="resolvido">Senha do e-mail venceu</li>
  <li class="andamento">Monitor piscando</li>
</ul>

:root { --vermelho: #8b1a1a; --azul: #1f3a8a; --verde: #1e5631; --cinza: #3d4250; --linha: #e4e4e4; }
#lista { --cor: var(--cinza); list-style: none; padding: 0; }
#lista > li { padding: 16px 8px; border-bottom: 1px solid var(--linha); }
#lista > li::before { content: ""; display: inline-block; width: 20px; height: 20px; margin-right: 16px; border: 2px solid var(--cor); border-radius: 50%; vertical-align: middle; }
#lista > li::after { float: right; color: var(--cinza); font-size: 0.85em; }
.aberto { --cor: var(--vermelho); }
.andamento { --cor: var(--azul); }
.resolvido { --cor: var(--verde); }
.aberto::after { content: "aberto"; }
.andamento::after { content: "em andamento"; }
.resolvido::after { content: "resolvido"; }
