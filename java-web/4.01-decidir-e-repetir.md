Você vai ser meu professor de JavaScript. Estou começando a programar: fiz uma aula de HTML, uma de CSS, uma de JavaScript (variável, função, querySelector, addEventListener) e acabei de fazer a aula de decidir e repetir.

O que eu já estudei nesta aula:
- if faz uma pergunta e roda o que está entre as chaves só se a resposta for sim; else é o caminho de quando a resposta é não. O if escolhe um dos dois caminhos, nunca os dois.
- Toda comparação responde true ou false. Três sinais de igual (===) perguntam se os dois lados são iguais; !== pergunta se são diferentes; maiúscula é diferente de minúscula. Um sinal de igual sozinho não compara: guarda um valor num nome. && quer dizer "e" e || quer dizer "ou".
- else if é "senão, se": as perguntas são feitas na ordem, a primeira que responder sim ganha, e o else do fim fica com todo o resto.
- Array é um nome que guarda vários valores em fila, entre colchetes. length é quantos itens ele tem. A posição começa do zero, e posição que não existe devolve undefined, sem erro.
- for (let i = 0; i < lista.length; i++) repete o que está entre as chaves: o i é o contador, a pergunta é feita antes de cada volta e o i++ soma um no fim de cada volta. for...of entrega um item por volta, sem contador.
- Objeto é um conjunto de campos com nome e valor, entre chaves; o ponto lê um campo (chamado.titulo).
- Um for com um if dentro conta, soma ou procura numa lista.
- while repete enquanto a resposta da pergunta for sim; eu usei pra esvaziar uma lista da página (firstChild e removeChild).
- switch olha um valor e compara com cada case; default é o caminho de quando nenhum caso bateu; num switch sem return, cada caso termina com break.
- Classe é o molde de onde os objetos saem: o constructor guarda os valores em this, e a classe pode ter uma função que o próprio objeto responde. new cria um objeto a partir da classe.
- trim devolve o texto sem os espaços das pontas, e push põe um item no fim do array.
- Um sinal de igual só dentro do if não dá erro: a linha guarda o valor, e um texto com alguma coisa dentro conta como sim. O programa fica errado sem reclamar.
